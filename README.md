# 车间布局规划 · SLP 小游戏

面向工业工程零基础入门者的 SLP（系统布置设计）体验小游戏。
用浏览器直接打开 `index.html` 即可游玩，无需安装任何东西。

## 玩法

1. **摆放**：点击下方工作台卡片拾取 → 在场地点击放下；拖动可移动，`R` / 右键旋转，`Del` 删除。
2. **限制**：工作台不能重叠、不能出界，相互之间至少保留 1 格（1m）通道。
3. **路线**：切换到「规划物流路线」→ 打开右侧「📊 评分 / 路线」面板（快捷键 `3`）的「🔗 路线」页选择一条路线（只能按工艺流程图规定的链接）→ 点击起点工作台 → 逐格点击画路径（只能横/竖走、不能穿过工作台）→ 点击终点工作台完成（选择路线后面板会自动收起，不挡场地）。
4. **评分**：在「📊 评分」页查看搬运时长、搬运效率、需搬运工人数；所有路线规划完后，搬运时长越短、效率越高、需要的搬运工越少，布局越好。
5. **演示**：点击「运行演示」观看物料沿路线流动（物流量大的路线粒子更密集；搬运越久的路线粒子走得越慢）。
6. **流程图**：点击左侧工艺流程图可放大查看；在大图上点击节点可直接定位已放置的工作台，或拾取未放置的工作台。

## 规则与评分

- **搬运时长（核心指标）**：每趟搬运时长 = 装卸 5s + 往返距离 ÷ 0.8 m/s（含空车返回，距离 ×2）；
  每条路线对每件成品的搬运时长 = 物流量 × 每趟时长
- 实际搬运时长 = Σ（物流量 × 每趟时长），单位「秒/件」
- 最短搬运时长 = 每条路线在当前布局下的最短可行距离（自动寻路得出）换算出的时长
- 搬运效率 = 最短 ÷ 实际 × 100%
- 需搬运工 = ⌈每件搬运时长 ÷ 瓶颈节拍⌉（瓶颈节拍 = 40s/件）
- 物流量 = Σ（该路线物流量 × 路线距离），单位「件·米/件」（辅助指标）
- 物流强度等级：A（≥4）绝对重要 / E（2~3）特别重要 / I（1）重要

## 想改参数？编辑 data.js

- `FLOOR`：场地大小（米）
- `STEPS`：工序（名称 / 设备 / 标准时间 `time` / 占地 `size` / 颜色）
- `LINKS`：工艺流程连线（`from` / `to` / 物流量 `flow`）
- `MIN_GAP`：工作台之间的最小通道宽度（格）
- `HANDLING`：搬运参数（每趟装卸 `fixedTime` / 搬运速度 `speed` m/s / 是否含空车返回 `roundTrip`）
- 流程图节点位置：`STEPS[i].pos`；特殊走线：`LINKS[i].path / lbl`
